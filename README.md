# Completed tasks as part of the JPMC Quant Research Simulator as administered by Forage   
This repository contains the following:   
- Task One: Build a time series forecast model to predict future natural gas prices and estimate past ones
- Task Two: Use model to write function which valuates a storage contract taking into account injection rates and prices as well as storage fees
- Task Three: Build a machine learning model from borrower data to make predictions about default probabilities
- Task Four: Use likelihood function techniques to create the optimal binning of borrows in credit score as to be used for a different architecture to make default predictions
